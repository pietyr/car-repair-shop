# System rezerwacji terminów napraw w warsztacie samochodowym

## Cel

Ułatwienie umawiania i zarządzania terminami napraw oraz ogarnięcie grafiku warsztatu.

## Docelowi użytkownicy

klienci warsztatu, recepcja / doradcy serwisowi, mechanicy (podgląd grafiku).

## Główne funkcje

1. Rezerwacja terminu naprawy (data, usługa, pojazd) przez klienta lub recepcję.
2. Kalendarz / grafik zajętości stanowisk i mechaników.
3. Potwierdzanie, odwoływanie i przenoszenie wizyt.
4. Powiadomienia (e-mail/SMS) o zbliżającym się terminie.
5. Panel statusów zleceń (oczekujące, w trakcie, zakończone).
